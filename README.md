📚 Estrutura de Dados — Lista Encadeada (Exercícios)

Este repositório reúne exercícios desenvolvidos na disciplina de Estrutura de Dados (ED), com foco em listas encadeadas e manipulação de dados em linguagem C.

Os exercícios abordam diferentes variações e operações sobre listas, reforçando conceitos fundamentais como alocação dinâmica, ponteiros e organização de dados.

🧠 Conteúdos abordados
Listas simplesmente encadeadas
Listas duplamente encadeadas
Listas circulares
Inserção ordenada
Manipulação de inteiros grandes
Operações básicas (inserção, remoção, busca)

🎯 Objetivo acadêmico

Este repositório tem como objetivo:
Consolidar o uso de ponteiros
Praticar alocação dinâmica (malloc/free)
Implementar diferentes tipos de listas encadeadas
Desenvolver raciocínio lógico na manipulação de estruturas
